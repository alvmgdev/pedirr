# Project instructions

Write source code, comments, commits, and documentation in English. Provide English and Spanish user interfaces.

For interface work, read and apply `.agents/skills/frontend-design/SKILL.md`. Favor deliberate typography, hierarchy, spacing, responsive layouts, and accessible interactions grounded in sports schedules.

Keep changes in small functional commits. Never invent upstream endpoints or silently expand the scope of a content request. Preserve existing Sportarr monitoring settings. Keep secrets out of responses and logs.
